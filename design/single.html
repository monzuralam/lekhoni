ওয়ার্ডপ্রেসটিউটোরিয়াল

হেডলেস ওয়ার্ডপ্রেস কী এবং কেন ব্যবহার করবেন

কনটেন্ট থাকবে ওয়ার্ডপ্রেসে, আর সাইট চলবে Next.js-এ। এই ব্যবস্থায় গতি, নিরাপত্তা আর ডিজাইনের স্বাধীনতা কীভাবে বাড়ে, সহজ ভাষায় জেনে নিন।

রহিম আহমেদ ২৮ সেপ্টেম্বর, ২০২৬ ৮ মিনিটে পড়া যাবে ৩টি মন্তব্য
১০০%
সূচিপত্র

ওয়ার্ডপ্রেস দিয়ে সাইট বানানো মানেই থিম, প্লাগইন আর PHP টেমপ্লেট, এমনটাই আমরা জানি। কিন্তু গত কয়েক বছরে আরেকটি ধারা জনপ্রিয় হয়েছে: হেডলেস ওয়ার্ডপ্রেস। এখানে ওয়ার্ডপ্রেস শুধু কনটেন্ট সামলায়, আর দর্শক যে সাইট দেখেন সেটা তৈরি হয় আলাদা একটি ফ্রন্টএন্ড দিয়ে।

এই লেখায় আমরা দেখব হেডলেস বলতে আসলে কী বোঝায়, কখন এটি কাজে লাগে এবং কখন লাগে না। শেষে থাকবে শুরু করার একটি ছোট চেকলিস্ট।

হেডলেস বলতে কী বোঝায়

সাধারণ ওয়ার্ডপ্রেসে "মাথা" হলো থিম, অর্থাৎ যে অংশ HTML তৈরি করে। হেডলেস ব্যবস্থায় সেই মাথা সরিয়ে ফেলা হয়। ওয়ার্ডপ্রেস তখন একটি কনটেন্ট API হিসেবে কাজ করে, আর Next.js-এর মতো ফ্রেমওয়ার্ক সেই API থেকে ডেটা নিয়ে পাতা সাজায়।

কনটেন্ট এক জায়গায় লিখুন, দেখান যেখানে খুশি: ওয়েবসাইটে, মোবাইল অ্যাপে কিংবা স্মার্ট ডিসপ্লেতে।

হেডলেস ধারণার মূল কথা

REST নাকি GraphQL

ওয়ার্ডপ্রেসে REST API আগে থেকেই আছে। তবে WPGraphQL প্লাগইন ব্যবহার করলে এক অনুরোধেই ঠিক যতটুকু ডেটা দরকার ততটুকু আনা যায়। নিচের কোয়েরিটি সাম্প্রতিক ছয়টি পোস্ট আনে:

query RecentPosts {
  posts(first: 6) {
    nodes {
      title
      uri
      excerpt
      featuredImage {
        node { sourceUrl altText }
      }
    }
  }
}

কেন হেডলেস ব্যবহার করবেন

সব প্রকল্পে হেডলেস দরকার হয় না। তবে নিচের সুবিধাগুলো আপনার কাছে গুরুত্বপূর্ণ হলে ভেবে দেখতে পারেন:

  • গতি: পাতা আগে থেকেই তৈরি থাকে, তাই দর্শকের কাছে পৌঁছায় চোখের পলকে।
  • নিরাপত্তা: ওয়ার্ডপ্রেস অ্যাডমিন জনসাধারণের সাইট থেকে আলাদা থাকে।
  • ডিজাইনের স্বাধীনতা: থিমের সীমাবদ্ধতা নেই, কম্পোনেন্ট দিয়ে যা খুশি বানানো যায়।
  • পরিচিত এডিটর: লেখকরা আগের মতোই ব্লক এডিটরে লেখেন।

কখন হেডলেস ঠিক পছন্দ নয়

ছোট ব্যক্তিগত ব্লগ, কিংবা যেখানে অনেক প্লাগইনের ফ্রন্টএন্ড ফিচার দরকার, সেখানে প্রচলিত থিমই সহজ সমাধান। হেডলেসে দুটি আলাদা সিস্টেম দেখাশোনা করতে হয়, সেটা মাথায় রাখুন।

শুরু করার ধাপ

  1. ওয়ার্ডপ্রেসে WPGraphQL প্লাগইন ইনস্টল ও চালু করুন।
  2. দোকান থাকলে WooGraphQL যোগ করুন।
  3. npx create-next-app দিয়ে নতুন Next.js প্রকল্প খুলুন।
  4. একটি ছোট fetchGraphQL() ফাংশন লিখে প্রথম কোয়েরি চালান।
  5. পোস্ট প্রকাশের ওয়েবহুক দিয়ে রিভ্যালিডেশন সেট করুন।

এক নজরে কিছু ছবি

ছবিতে ক্লিক করলে বড় করে দেখা যাবে, তীর চিহ্ন দিয়ে পরের ছবিতে যাওয়া যাবে।

শেষ কথা

হেডলেস ওয়ার্ডপ্রেস কোনো জাদু নয়, এটি একটি স্থাপত্য-সিদ্ধান্ত। আপনার দলে জাভাস্ক্রিপ্ট জানা মানুষ থাকলে এবং গতি ও ডিজাইনের স্বাধীনতা জরুরি হলে এটি দারুণ কাজ করে। পরের লেখায় আমরা WPGraphQL দিয়ে প্রথম কোয়েরি লিখব।
